¿Qué conviene anotar sobre un aura?

Describe el síntoma con tus palabras, la hora de inicio, cuánto duró, si cambió con el tiempo y cuándo apareció el dolor. Anota también si era la primera vez o si fue distinto de otros episodios y comunícalo a un profesional.

El aura no es igual para todo el mundo

MedlinePlus describe el aura como una fase posible, no universal, que puede producir alteraciones visuales u otros síntomas neurológicos. Mayo Clinic indica que la evaluación considera los síntomas, antecedentes y examen físico; no existe una única prueba específica para confirmarla.

Una cronología clara

  1. Anota la hora exacta o aproximada del primer cambio.
  2. Describe lo observado o sentido sin elegir una causa.
  3. Registra si evolucionó, se desplazó o desapareció.
  4. Anota cuándo comenzó el dolor u otros síntomas.
  5. Incluye cualquier diferencia respecto a episodios anteriores.

Primera vez o cambio importante

Las alteraciones visuales, sensoriales o del lenguaje también pueden tener otras causas. Si son nuevas, diferentes, prolongadas o preocupantes, busca valoración médica. El diario puede apoyar la conversación, pero no decide qué ocurrió.
