01 / FOVRI KITCHEN NOTE

Start small and useful

Do not import every recipe you have ever liked. Begin with ten meals you already cook or genuinely plan to make. This creates a trustworthy core instead of a second endless feed.

Add new recipes only when they pass a simple test: would you consider cooking this within the next month?

02 / FOVRI KITCHEN NOTE

Use a consistent recipe format

  • Specific, searchable title
  • Realistic serving count
  • Ingredients with units
  • Ordered cooking steps
  • Original source link
  • Your own notes after cooking

03 / FOVRI KITCHEN NOTE

Organize for retrieval

Use folders for repeated decisions—quick dinners, baking, guests, lunch—not for every cuisine and ingredient. Favorites should mean “worth repeating,” not merely “looks good.”

Ingredient search can often do the work that dozens of tiny folders cannot.

04 / FOVRI KITCHEN NOTE

Back up and review

Choose a tool with an export or backup path and use it periodically. Review uncooked saves every few months: plan them, improve them or remove them.

Fovri keeps cookbook data locally on the iPhone and includes export and restore tools for backups you control.
