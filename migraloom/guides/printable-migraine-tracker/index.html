Quick answerHow do you code a compact migraine tracker?

Define one consistent code. Leave a day blank when it was not recorded, use a personal severity scale and mark medication only when actually recorded.

How to make the calendar useful

  • Write the meaning of every code at the top.
  • Keep “not recorded” separate from “symptom-free.”
  • Use one severity scale throughout the period.
  • Link unusual days to a longer episode note.
  • Review totals as questions, not conclusions.

What a compact tracker leaves out

A 90-day overview can show recorded frequency but has little room for timing, symptoms, impact or medication detail. Keep an episode record when those details matter.
